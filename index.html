Code Pemrograman

HTML

HTML berfungsi sebagai penyusun struktur dasar sebuah halaman web. Semua elemen di dalam web—seperti teks, gambar, tombol, tabel, form, dan link—dibuat menggunakan HTML. HTML juga menentukan bagian-bagian penting halaman seperti header, main content, sidebar, dan footer. Tanpa HTML, browser tidak punya “isi” atau komponen yang bisa ditampilkan. Jadi inti fungsi HTML adalah membentuk kerangka dan menyusun setiap elemen yang tampil di halaman.

CSS

CSS berfungsi untuk mengatur tampilan dan gaya visual dari elemen-elemen HTML. Dengan CSS, tampilan website menjadi lebih rapi, menarik, dan profesional. CSS mengatur warna, jenis dan ukuran font, jarak antar elemen, posisi layout, bentuk tombol, hingga efek transisi atau animasi. Selain itu, CSS memungkinkan desain responsif, yaitu tampilan yang berubah mengikuti ukuran layar HP, tablet, atau laptop. Tanpa CSS, semua halaman web akan terlihat polos dan tidak nyaman dilihat.

JavaScript

JavaScript berfungsi untuk memberikan interaksi dan logika pada website agar tidak hanya statis. Dengan JavaScript, elemen web bisa merespon tindakan pengguna—misalnya ketika tombol diklik, form dicek sebelum dikirim, membuat slide show, membuka popup, hingga mengubah konten tanpa perlu me-reload halaman. JavaScript juga dapat berkomunikasi dengan server (misalnya mengambil data tanpa memuat ulang), sehingga web bisa terasa seperti aplikasi. Intinya, JS membuat website hidup, interaktif, dan dinamis.
